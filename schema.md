# Database Schema & Field Documentation

## Overview
The dataset contains raw user interaction and session lifecycle events generated by the interactive player.

## Schema Definition (`events` Table)

| Field Name | Expected Data Type | Nullable | Primary / Foreign Key | Description |
| :--- | :--- | :--- | :--- | :--- |
| `event_id` | `VARCHAR(32)` | No | Primary Key | Unique identifier for each individual event. |
| `timestamp` | `TIMESTAMP` | No | - | UTC timestamp when the event occurred (`YYYY-MM-DDTHH:MM:SSZ`). |
| `user_id` | `VARCHAR(32)` | Yes | Foreign Key | Identifier for the user. Nullable for unauthenticated/guest users. |
| `session_id` | `VARCHAR(32)` | Yes | Foreign Key | Identifier grouping user events in a single continuous session. |
| `event_name` | `VARCHAR(64)` | No | - | Name/type of event (`session_start`, `page_view`, `video_play`, `session_end`, `interaction_click`, `checkout_started`, `purchase`, `video_rewind`). |
| `clip_id` | `VARCHAR(64)` | Yes | Foreign Key | Identifier for the specific video/interactive clip context. |
| `interaction_id` | `VARCHAR(64)` | Yes | - | ID of the specific UI element clicked (populated for `interaction_click` events). |
| `properties` | `JSON` / `MAP` | Yes | - | Additional metadata (e.g., `device`, `page`). |

## Inferred Relationships
1. **User to Sessions (`1 : N`)**: A single `user_id` can be linked to multiple `session_id` records.
2. **Session to Events (`1 : N`)**: A single `session_id` groups multiple events sequentially over time.
3. **Clip to Events (`1 : N`)**: Events occur in the context of interactive video clips (`clip_id`).
